## 📌 Project Overview

This project explores retail order activity using **MySQL** and **Microsoft Power BI**. The interactive report presents order patterns across product categories, regions, customer segments, and months.

## 🎯 Objectives

- 📊 Build an interactive business dashboard.
- 🧮 Analyze order activity using SQL.
- 📅 Explore monthly order patterns.
- 🧭 Compare activity across categories, regions, and customer segments.
- 💡 Present findings and practical recommendations clearly.

## 🔍 Key Observations

Based on the current dashboard visuals:

- 📦 **Category:** Office Supplies leads the displayed category comparison.
- 🌎 **Region:** The West region has the highest displayed regional order count; the South has the lowest.
- 👥 **Customer segment:** Consumer customers account for the most orders in the displayed comparison.
- 🗓️ **Monthly trend:** Order activity peaks around September and November in the displayed chart.

> ⚠️ These are descriptive observations from the current visuals. Verify the source data, measures, and date range before using them in formal reporting. This project focuses on order activity; do not interpret order counts as sales or profit performance.

## 🚀 How to Use

1. ⬇️ Clone or download this repository.
2. 🖥️ Open `Retail_Sales_Analysis.pbix` in Power BI Desktop.
3. 🔌 If prompted, reconnect the report to the dataset or update the data source path.
4. 🎛️ Navigate between the report pages and use the Month slicer to explore the visuals.
5. 🗄️ Open `retail_analysis.sql` in MySQL Workbench to review the SQL analysis queries.
